# 教育经历

一个文件代表一段学历经历（高中、专科、本科、硕士、博士各算一段）。

## 实例

- 文件名：`<学校名>-<学历简称>.md`。学历简称只用五个：`高中`、`专科`、`本科`、`硕士`、`博士`，与 `学历` 属性的取值一一对应（`高中`→`高中`、`专科`→`专科`、`本科`→`本科`、`硕士研究生`→`硕士`、`博士研究生`→`博士`）。
- 学校名与学历之间用半角连字符 `-`；同一学校有多段学历时靠这个后缀区分，不会再撞名。
- 多份实例之间靠 `入学时间` 区分先后。

## 必备实例

- 高中：应届生、在读生与校招场景必备。多数校招系统的教育经历要求从高中填起，而简历通常不写高中段，没有时必须向用户确认；走社招、用户确认不需要时，记到简历文件夹的根 `README.md` 的「已确认没有的项」里。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`；标 `（高中段可空缺）` 的条目在高中实例里整行不写。
- 还在读的一段：`毕业时间` 填预计毕业时间；`毕业证书`、`学位证书` 本来就是可空缺的，在读段直接不写这两行。学校还没开出在读证明时，`教育经历证明` 标 `待补` 等用户提供。
- `是否专升本` 只对本科段有意义，其他学段标 `〔不适用〕`。
- `受教育类型`、`教育类别`、`是否全日制` 是同一件事在不同网站上的字段名，取值必须保持一致。
- `是否最高学历`、`是否最高学位`、`是否主要学习经历` 需要横向比较全部实例后统一填写，通常只有一段为「是」，不要逐段孤立判断。
- `平均成绩` 与 `平均学分绩点` 要写清口径（加权还是简单平均、满绩是多少）。网站只要单个数字时取实际值；字段名带 GPA/CGPA 时把满绩一并写上。
- `年级排名` 按实际填；网站只提供档位时选最接近的档，并在实例的 `## 备注` 里写清映射关系。
- 证书类附件按学历段命名（如 `<学历段>毕业证书.jpg`），挂到对应那一份，不要互相覆盖。
- `专业类别` 写「门类-专业类-专业」的层级写法；网站只给门类下拉时取第一段。
- `部分课程` 只在网站要求填课程清单时使用；没有要求就不用写，也不要编造课程名。

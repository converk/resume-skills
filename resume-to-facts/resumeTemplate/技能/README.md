# 技能

一个文件代表一类技能知识。技能描述按类归拢，不要一个技能点一个文件。

## 实例

- 文件名：`<技能类名>.md`。
- 类的划分按用户自己的知识结构来，通常 2~4 类即可。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`。
- `技能描述` 按条目组织，一条写一个方向：先写技术名词，再写能做到什么程度，便于网站按关键词筛选与按字数裁剪。
- 描述里不要写没有把握的"精通"；用"熟悉/掌握/了解"这类可核实的措辞。
- `是否持有相关证书` 写「是」或「否」。写「是」时，`证书` 子表至少要有一条。
- 证书指技能类证书（等级考试、资格认证等）。语言类证书放 `外语能力/`，学术奖项放 `获奖情况/`。
- 技能描述常被网站按字节数限制裁剪，写的时候把最重要的方向放在最前面。
- 证书扫描件放本类目录内，属性值写相对工作区根目录的路径。

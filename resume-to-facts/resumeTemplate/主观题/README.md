# 主观题

一个文件代表一类主观问题。网站问什么，就从对应的文件取。凡是"没有唯一正确答案、要看投递对象临时组织语言"的内容都放这一类，比如对某家单位的看法、自我评价、毕业论文简述、性格、个人爱好、职业规划等。

## 实例

- 文件名用问题名。
- 本类**不限制命名方式**：问题名可以带上适用场合，怎么分怎么起由你决定，一个文件代表一类问题内容即可。
- 同一个问题有多种长度版本时，写在**同一个文件**里，用 `描述（完整）`、`描述（简短）` 两个属性区分；版本更多时按同样写法加属性，不要拆成多个文件。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`。
- `适用场合` 写这份内容适合投给什么对象（行业、岗位类型等）。多份内容对应不同场合时，填写方按投递对象选用。
- 客观陈述与主观表述分开：可核实的事实（学校、职位、成果）写进对应的经历类，这里只写主观表述与动机。
- 每份内容都要能独立使用，不要出现"同上""见某某文件"这类互相引用。
- 涉及特定公司的内容只保留通用句式，公司相关的具体表述在投递时按目标公司补写，不要复用另一家公司的说法。
- 主观题几乎都会遇到字数限制。写出完整版即可，短版按"做了什么、结果是什么"保留，砍掉铺陈与形容。

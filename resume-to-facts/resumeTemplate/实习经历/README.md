# 实习经历

一个文件代表一段实习经历。

## 实例

- 文件名：`<公司简称>.md`。
- 同一公司有多段实习时，文件名加时间或岗位区分。
- 一段实习就是一段，跨年不拆分。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`。
- 简历上"实习、工作经历"常写在同一栏，里面可能同时装着实习与全职；按时间跨度与职位性质拆开，实习进本类，全职进 `全职工作经历/`，不要合并成一个文件。
- `公司名称` 写行业内的常用简称；网站要求全称时用 `公司全称`。拿不到工商全称就标 `待补`，不要自行推敲。
- 还在实习中：`离职时间` 按合同或预期写；网站没有"至今"选项时填当月，并在报告里说明这是权宜填法。
- `技术栈与方向`、`业务方向` 是给筛选用的短标签，写关键词而不是句子。
- `工作描述` 按条目组织，一条讲一件事。网站有字数限制时按限制增减条目，不要整段砍尾巴。
- `证明人` 是可选信息：用户不愿提供时整段省略，并在实例的 `## 备注` 写明"用户未提供证明人"。
- 实习证明文件放本类目录内，属性值写相对工作区根目录的路径。

# 个人信息 · 属性模板

一个文件对应一个人。一行一条属性：`形态` 说这条在实例文件里写成什么样，`必填性` 说什么时候必须有个交代，`取值` 只是可选值提示，不参与必填判断。

| 属性 | 形态 | 必填性 | 取值 | 说明 |
| --- | --- | --- | --- | --- |
| 姓名 | 单值 | 必填 | — | 证件上的汉字全名 |
| 姓名拼音 | 单值 | 必填 | — | 姓在前、名在后，按护照或证件的拼法；网站要英文名时按它的习惯顺序重排 |
| 国籍 | 单值 | 必填 | — | 写通用国名，如「中国」 |
| 性别 | 单值 | 必填 | 男/女 | 与证件一致 |
| 出生日期 | 单值 | 必填 | YYYY-MM-DD | 与证件一致；年龄由它现算，不单独存 |
| 民族 | 单值 | 必填 | — | 如「汉族」，按证件写 |
| 婚姻状况 | 单值 | 必填 | 未婚/已婚/离异/丧偶 | 按实际情况写 |
| 健康状况 | 单值 | 必填 | — | 如「健康」；有其他情况按用户口径写 |
| 身高 | 单值 | 必填 | cm | 只写数字 |
| 体重 | 单值 | 必填 | kg | 只写数字 |
| 证件类型 | 单值 | 必填 | 身份证/护照/港澳通行证/其他 | 大陆求职一般填身份证 |
| 证件号码 | 单值 | 必填 | — | 按证件原文抄写，不要改字母大小写 |
| 证件有效期 | 单值 | 必填 | YYYY.MM.DD–YYYY.MM.DD | 按证件原文的粒度写；长期有效就照原文写 |
| 身份证人像 | 附件 | 必填 | — | 相对工作区根目录的路径，文件放本类目录 |
| 身份证国徽 | 附件 | 必填 | — | 同上 |
| 证件照 | 附件 | 必填 | — | 同上，用于简历与招聘系统的头像栏 |
| 生活照 | 附件 | 必填 | — | 同上，部分系统要求近照 |
| 简历文件 | 附件 | 必填 | — | 本人最新版简历源文件（PDF/Word） |
| 出生地 | 单值 | 必填 | 省-市-区县 | 与籍贯、生源地、户口所在地相互独立 |
| 籍贯 | 单值 | 必填 | 省-市-区县 | 同上 |
| 高考生源地 | 单值 | 必填 | 省-市-区县 | 同上 |
| 户口所在地 | 单值 | 必填 | 省-市-区县 | 同上 |
| 户口性质 | 单值 | 必填 | 城镇/农村 | 只在这两个值里选 |
| 现居住城市 | 单值 | 必填 | 省-市-区县 | 填实际长期居住地，不是籍贯 |
| 全日制最高学历 | 单值 | 必填 | 高中/专科/本科/硕士/博士 | 与 `教育经历/` 的 `学历` 口径一致 |
| 取得最高学位时间 | 单值 | 必填 | YYYY-MM-DD | 已毕业写实际时间，在读填预计时间 |
| 政治面貌 | 单值 | 必填 | 中共党员/共青团员/群众/其他 | 按实际情况写 |
| 入党时间 | 单值 | 必填（非党员可空缺） | YYYY-MM-DD | 非党员标 `〔不适用〕` |
| 入团时间 | 单值 | 必填（非团员可空缺） | YYYY-MM-DD | 非团员标 `〔不适用〕` |
| 手机号码 | 单值 | 必填 | 11 位 | 招聘方会打这个号，填常用号 |
| 电子邮箱 | 单值 | 必填 | — | 长期有效、常用 |
| 通信地址 | 单值 | 必填 | — | 能实际收到信件的地址 |
| 邮政编码 | 单值 | 可空缺 | 6 位数字 | 与通信地址对应 |
| 个人主页 | 单值 | 可空缺 | URL | 如 GitHub、博客、作品集 |
| 紧急联系人姓名 | 单值 | 必填 | — | 通常填一位 |
| 紧急联系人关系 | 单值 | 必填 | — | 如「母亲」 |
| 紧急联系人电话 | 单值 | 必填 | — | 需向用户单独确认 |
| 期望薪资范围 | 单值 | 必填 | 税前月薪区间 | 用户不确定时标 `待补` |
| 服兵役 | 单值 | 必填 | 有/无 | 没有就写「无」 |

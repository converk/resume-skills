# 个人信息

这个文件夹记录本人的身份、户籍与联系方式。一个文件对应一个人。

## 实例

- 文件名：`<姓名>.md`。
- 求职场景下通常只有一个实例；替他人建库时才需要多个。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`；标「必填」的条目每个实例都要有交代。
- 年龄不单独存属性：网站要年龄时按 `出生日期` 与当天日期现算，不要写死一个数字。
- `取得最高学位时间` 指最高学历对应学位的取得时间：已毕业写实际取得时间，还没毕业写预计取得时间；它通常与 `教育经历/` 里最高学历那一段的 `毕业时间` 一致。
- 出生地、籍贯、高考生源地、户口所在地是四个独立属性，取值相同也要分别填。
- 户口性质只写「城镇」或「农村」。网站另有"是否本地户口"这类问题时，按户口所在地与目标城市是否一致现场推导，不单独存属性。
- 证件有效期按证件原文的粒度写；网站要求具体日期时取证件上的起止日期。
- 照片与证件类附件都写相对工作区根目录的路径，文件放在本类目录内。
- 毕业证书、学位证书属于具体某一段学历，放在 `教育经历/` 并挂到对应那一段，本文件夹不放。网站上"上传已获取的毕业证书/学位证扫描件"这类栏位去 `教育经历/` 取。
- `简历文件` 指本人最新版简历的源文件（PDF/Word），供下载与上传使用。
- 紧急联系人通常填一位；网站要两位时，第二位需要在提问清单里向用户补。
- 期望薪资范围按税前月薪写；用户不确定就标 `待补`，不要替他定一个数。
- 服兵役按实际写，没有就写「无」。

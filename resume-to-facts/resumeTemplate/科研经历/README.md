# 科研经历

一个文件代表一篇论文或一项科研工作。

## 实例

- 文件名：`<论文缩写>.md`，没有缩写时用标题中的关键短语。
- 同一论文的不同版本（会议版、期刊版）算一个文件，版本差异写进实例的 `## 备注`。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`。
- `论文名称` 用论文原题；`中文名称` 是题目对应的中文表述，只翻译需要翻译的部分，缩写与专有名词保持原样。
- 网站要求填"论文题目"时用 `论文名称`；网站把这项成果放在"项目名称/项目经历名称"这类字段时用 `中文名称`。
- `状态` 是在投时，网站问发表时间、卷期号、页码一律留空或如实说明"在投"，**不要填预计时间**。
- `级别` 只写能确证的定级信息。会议类投稿没有期刊分区概念，不要写分区或 SCI；有 CCF、JCR 等分级体系时按体系写。
- `投稿去向` 写会议或期刊名称，并附上定级说明；面向非专业读者（HR、非本方向的面试官）时必须把定级显式写出来，只写缩写他们看不懂。
- 网站只提供"期刊分类"这类档位、又没有"会议"选项时：会议类投稿选最接近的"其他/其他刊物"，会议名称填进期刊名称字段，定级写进详情，发表时间留空。
- `详细描述` 是一段面向非同行也能读懂的中文改写，不要堆砌指标与数字；有指标时单独写，别混进描述里当卖点。
- 多篇论文时，网站栏目容量有限，按与投递岗位的相关度取舍，取舍口径写进实例的 `## 备注`。

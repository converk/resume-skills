# 外语能力

一个文件代表一门外语，记录这门语言的掌握情况与相关成绩。

## 实例

- 文件名：`<语言名>.md`。
- 只有一门外语时就只有一个文件。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`。
- `证书` 是子表：一条证书一个 `### 证书：<名称>` 段落，同一门语言可以有多条。
- `名称` 写考试或证书的通用简称，不要写成全称或机构名；同一证书考过多次时，在名称后加时间区分。
- `分数` 按成绩单原文写；只有等级没有分数的，就把等级写进 `分数`，或改成"合格/良好"这类原文口径。
- `掌握水平` 用一句人话描述实际运用能力，不要只写"良好"；网站要"熟练程度"下拉时按这句话映射到最接近的档位。
- 没有证书、只有水平的语言，整段省略证书子表。
- 语言类证书的扫描件放本类目录内，属性值写相对工作区根目录的路径；技能类证书属于 `技能/`。

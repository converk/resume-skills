# 校内活动和社会实践

一个文件代表一段校内任职或社会实践经历（学生干部、社团任职、支教、志愿服务等）。

## 实例

- 文件名：`<组织或场合>_<职务>.md`；职务本身就是唯一标识时可以直接用 `<职务>.md`。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`。
- `活动起止时间` 写成区间，形如 `起 至 止`。
- `级别` 按任职范围取字段清单里给出的档位；确实没有级别可言的志愿服务可以整行不写。
- `工作描述` 按条目组织，强调做了什么、结果是什么；网站有字数限制时按限制增减条目。
- 社会实践与志愿服务如果没有明确的"职务"，`职务` 写实际承担的角色。
- 招聘网站没有专门的校内活动栏时，这里的经历可以按 `项目经验/` 的降级规则改填到项目或其他经历栏。

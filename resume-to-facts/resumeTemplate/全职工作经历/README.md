# 全职工作经历

一个文件代表一段正式（非实习）工作经历。

## 实例

- 文件名：`<公司简称>.md`。
- 同一公司有多段经历（离职后再次入职）时，文件名加时间或部门区分。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`。
- `公司名称` 写公司主体名，必要时带上所属层级；`公司全称` 填工商全称，拿不到就标 `待补`。
- 还在职：`离职时间` 按实际或"至今"的口径写；网站没有"至今"选项时填当月，并在报告里说明。
- 在职期间做的项目记到 `项目经验/`，这里的工作描述只保留一句概括，避免同一件事在两处各写一份长文。
- `工作描述` 按条目组织，可按网站字数限制增减条目。
- 多数公司不提供工作证明文件；拿不到时把 `工作证明` 标 `待补`，或按用户确认标 `〔不适用〕`。
- `证明人` 是可选信息，用户不愿提供时整段省略，并在实例的 `## 备注` 写明。

## 填写位置

招聘网站没有"全职工作经历"这类栏目时（常见于只面向在校生的校招系统），把这个类的实例填进"实习经历"栏，不要因为没地方放就整段丢掉：

- 按实习经历的格式填：公司名称、部门名称、岗位名称、起止时间、工作描述照抄过去。
- 保留"这是全职"的信息：在岗位名称后加"（全职）"这类标注，或在工作描述开头加一句说明。
- 不要为了迁就栏目把经历性质改写掉——全职不要写成实习，起止时间、公司、岗位都按事实填。
- 网站本身就是"工作/实习经历"合并栏时，一处填一份即可，不要重复提交两份。

# 获奖情况

一个文件代表一项奖励或荣誉（奖学金、荣誉称号、竞赛名次、公司内部表彰等）。

## 实例

- 文件名：`<奖励名称>.md`。
- 同名奖励获得多次时，文件名加年份或序号：`<奖励名称>_<年份>.md`。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`。
- `时间` 按颁发时间写；只记得年份时就写年份，不要编造月日。
- `级别` 按颁奖范围写，取值只有四个：国家级、省级、校级、院系级。网站只提供少数档位时选最接近的，并在实例的 `## 备注` 里写清映射关系。
- `奖励描述` 写这项奖励的评选口径或获奖比例（能拿到才写）；拿不到就写一句简短说明，不要写空话凑长度。
- 没有获奖证书扫描件时 `证明` 标 `待补` 等用户提供；用户明确说没有就标 `〔不适用〕无证书`。
- 简历上常把多项奖励压成一句话，这种情况要拆成多条实例，分别补时间与级别。
- 证书扫描件放本类目录内，属性值写相对工作区根目录的路径。

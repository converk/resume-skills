# 家庭成员情况

一个文件代表一位家庭成员（父母、配偶、兄弟姐妹等）。

## 实例

- 文件名：`<姓名>.md`。用姓名而不是关系命名，避免将来出现同关系的多位成员时重名。

## 注意事项与降级

- 属性清单见同目录的 `模板.md`；本类属性全部必填，拿不到的值也不能整行省掉。
- `关系` 写口语关系（父亲、母亲、配偶、兄弟姐妹等）；`关系（表格口径）` 写表格列头那种由父/母与子/女组合成的写法。网站问"关系"用前者，表格列头是后者这种写法时用后者。
- 家庭成员的籍贯、户口所在地与本人常常相同，但**不要互相复制**：分别按各自的实际情况填。
- 现住地址与籍贯、户口所在地是三件事，取值不同时不要互相覆盖。
- 退休或没有工作单位的，`工作单位`、`职务` 按实际写「无」或「退休」，不要留 `待补`。
- 出生日期、政治面貌这类信息如果用户确实不知道，写「不详」并在实例的 `## 备注` 记一笔，不要留 `待补` 占位。
- 联系电话拿不到时标 `待补`，家庭成员的联系方式通常需要单独问用户。
- 网站只要"家庭成员有无在某单位任职"这类合规问题、不需要全部字段时，仍按本类填全，由填写方按需取用。

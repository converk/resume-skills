# 表单字段 → 简历文件夹里的类 的映射方法

## 方法

1. 读字段的标签、提示文案、是否必填、选项列表、字数或字节上限。
2. 判断它问的是哪一类事实：身份 / 学籍 / 经历 / 成果 / 主观表述。
3. 到对应类里选实例。多实例类按"与投递岗位相关度""最近一段""网站只能填一条"这些规则取舍，具体规则写在类 README 的 `## 注意事项与降级`。
4. 判断取哪个版本。有多档字数或字节版本的，取不超过限制的最完整版本。
5. 语义上无法确定归属的字段，宁可多问一句，不要猜一个填上去。

| 表单上的字段 | 取哪里 |
| --- | --- |
| 姓名、姓名拼音、证件类型、证件号码、证件有效期 | 个人信息 |
| 出生日期、性别、民族、婚姻状况、身高、体重、健康状况 | 个人信息 |

| 出生地、籍贯、户口所在地、户口性质、生源地、现居住城市 | 个人信息（四个"地"是独立属性，不要互相顶替） |

| 紧急联系人及其电话 | 个人信息 |

| 学校、学历、学位、培养方式、学制、是否全日制 | 教育经历 |
| 院系、专业、专业类别、研究方向 | 教育经历 |

| 自我评价、职业规划、个人爱好、选择理由、其他补充 | 主观题 |

## 没有对应栏目时

先看类 README 的 `## 填写位置`；没写时按"对应经历类 → 校内活动和社会实践 → 自我评价 / 其他补充信息"的顺序降级，并在最终报告里说明降到哪里去了。

## 同一件事要填多处

同一件事在不同栏目各填一处时，按各自栏目的字数和口径单独裁剪，不要互相复制长文。

## 字数与字节

- 中文站点有的按字符计，有的按字节计（汉字 2 字节）。两个口径都估一遍，取更保守的那个。
- 裁剪顺序：先砍铺陈与形容词，保留"做了什么 + 结果是什么"；指标与数字最后才砍。
- 上限很紧时优先保留可核实的硬事实（公司、学校、职位、时间、数字）。
